# 04 人物与对话——《诡舍》人物塑造体系拆解

> 样本：开场1-10章、19个单元首/中/尾章采样、番外与感言采样；关键引文已对回分章全本验证。
> 体例：左列「可复用模板」，右列「原文证据」。

## 一、主角能力设计：职业感官型"侦探"，绝不做超凡者

作者完本感言明言："诡舍的世界观和主角拥有的力量是不成正比的"——宁秋水到结局也只是一个"专业的人"。他的破局手段全部来自职业感官+现场勘查，恐怖感因此永不失效：他赢靠的是"看得比别人多一眼"，而不是武力。

| 设计模板 | 原文证据 |
|---|---|
| **职业=感官挂件**：给主角一个"天天与专业对象打交道"的职业，把职业训练直接翻译成侦查能力，且第一次出场就自我介绍 | "我是医生。""哦~难怪，法医？""差不多，兽医。"（第1章）；"我以前是兽医，对于气味也尤其敏感……人血是有一股明显的铁锈味……百分之百是人血。"（第3章） |
| **能力落地为"三查"**：查物（痕）、查屋（结构异常）、查人（行为矛盾） | 查物："少了一对……吃牛排的刀叉。"（第5章）；查屋："这个家里……根本没有男人的鞋子！"（第6章）、走廊灯是单向开关（第8章）；查人：大巴上"主动交换位置的人，必然都是诡客在寻找自己的同伴"（公路，第695章全句） |
| **能力有天花板**：只能观察推断，不能对抗；面对诡照样腿软、冒汗 | 处决水人时"宁秋水的心脏跳动慢了一拍……他还是会紧张。无论经历多少次"（水中来客）；第9章被刀叉声逼到"他抬起了手，下意识地就想要开灯！光……他需要光！" |
| **破局靠规则而非力量**：先摸清"死亡条件"，再在规则缝隙里行走 | "它不能肆无忌惮地杀死我们。只有当我们触发了'死亡条件'之后，它才可以对我们动手。"（第9章）；背诵信件规则硬闯："【风不点灯，雨不燃烛】【日不登楼，夜不瞑目】"（第9章） |
| **副业反差**：白天身份越普通，暗面越狠，两副面孔都是"真" | "我是一名兽医，专门负责治疗或是清理这座城市之中的……野兽。你也可以叫我【棺材】。"（送信单元） |

**冷静破局的行为序列（可直接套用）**：①异常入眼（别人只觉渗人，他多看一眼）→②先稳住同伴（"今晚，不要睡着，不要开灯，不论听见什么……都不要理会"，第4章）→③自己先上（"在他恐惧之中……迈出了脚"）→④小成本验证（喂白粥试"肉没熟"，贴耳听第三字，第5-6章）→⑤留验证悬念到夜晚（"这个猜想要今晚才能够得到验证"）。注意他从不解释到说破为止——"暂时还不能说""很多疑惑……应该今晚就会有答案了"，把解释变成下一章钩子。

## 二、主角弧光与内心戏

**开场立住三板斧**（第1章内完成）：①人群中第一个开口定方向（"走吧……我们已经没有其他的选择了"）；②"害怕但反应比众人小"被旁观者视角反复确认（"他的反应都远没有众人那么大"（第1章，叙述者陈述）——旁证式降温，比自己夸可信十倍）；③留一个信息差私人钩子（神秘信件，"这件事情，他一直没有告诉其他人"）。

| 内心戏写法 | 原文证据 |
|---|---|
| **害怕：写生理冲动被意志压住的那一秒** | "其实他心跳快得很。"紧跟着"宁秋水深吸一口气，努力让自己表现得平静"（第1章）；想开灯的手"硬生生地停住了"（第9章） |
| **害怕：给恐惧一个"人设化出口"** | "我也很紧张。""但不同的人，表现紧张的行为不同。""我一紧张，就喜欢吃点或是喝点东西。"——门外在磨刀，他在喝茶（第9章） |
| **果断：短句+反问，不抒情** | "你觉得，我们有得选吗？"（第1章）；"不用管，它会清理的。"（第7章）；"难收？那就别收了。你是覆水，我也是。弄死『他们』。"（逃出生天） |
| **弧光：冷静是壳， casualty 才露缝** | 君迢迢死后："自从他入行之后，很少再会感受到生命的脆弱，他以为自己已经麻木了。但是现在……却带给了宁秋水莫名的触动"（古宅惊魂）；对镜中遗照"至始至终，他都没有看清……现在……他已不想看清"（不存在的客人） |
| **自我怀疑型独白只给一句，随即收住** | "连他自己都没有意识到，自己的脑子为什么会……这么好用。"（第6章）——为后期"疯子/换命"暗线埋钉，当下不展开 |

## 三、单元配角模板：六原型 + 领盒饭节奏

19个单元中，临时人物平均每单元6-10人，单元长度15-78章；**炮灰存活约2-4章，功能配角约半程死亡，能活着上大巴的通常不超过进场人数一半**（古宅16→9，灯影寺8→3，血云书院13→4）。

| 原型 | 功能与写法 | 原文实例 |
|---|---|---|
| **引导者NPC** | 半人半诡，说话只说七分，关键情报藏在重复动作里 | 管家尼尔："夫人不喜欢外人进入三楼"说了三遍，宁秋水悟出"与其说这是警告……是一种提示"（黑衣夫人）；小和尚法华（灯影寺）；三鬼洋洋（血云书院）；鬼童小桃子（水中来客） |
| **背叛者** | 恐惧驱动的常态人性，"不害人但绝不防不住人" | 杜付元/于妍诱王九钏夜行（不存在的客人）；文雪给对手通风报信（亡羊补牢）；拿『信』做局的唐仁方倪（抬头的人）；"血门里危险的往往不仅是故事里的鬼怪，还有一同进入的伙伴"（古宅惊魂） |
| **牺牲者** | 主动断后+一件遗物完成人物一生速写 | 君迢迢："帮我个忙……如果最后我死了，请将这个带到昆华医院……交给一个叫君鹭远的人"，随后被活剥皮；死后从剧本里读到结局，宁秋水"喉咙处竟然有一丝干涩"（古宅惊魂） |
| **隐藏诡** | 队伍里最普通的那一个就是它；回收前文闲笔 | 眼镜男=无头僧人："你不是一直在找自己的头吗？"（祈雨村）；导演郑超=鬼本体钢笔（古宅）；海哥=相机（逃出生天） |
| **幸存同伴** | 保留1-2个跨单元回收的活人，做世界观接头人 | 曹立雪/鲁丰林（雨墓，粗中有细："咱们要不要给鬼尸多找点头"）；丰鱼从古宅活下来后把白潇潇推荐给杨眉（血云书院）；"苟王"杨一博文 |
| **情感共鸣位（死者视角）** | 用一章独白让炮灰变"人"，死亡即控诉 | 王文心的自述与幻象重演（逃出生天）；刘春被亲母撕皮："逃学的孩子留着已经没用了……"（血云书院）；阳佘捧着父亲的人头（守灵） |

**死亡书写的克制与冲击点**：①只给结果不给过程——"鲜血，已经从葛凯身体的每一个孔洞中渗出，流了一地……"（抬头的人）；②日常动作中骤停——唐仁对小方说了三次"救救我"，"然后就在方倪还没有反应过来时，碎了一车……"；③死状微笑——王雨凝、林风（头转180度看天）死时都"挂着诡异的微笑"；④迟一步即死——冯宛铭"自己……竟然倒在了最后一步。就只是因为短暂的，几秒钟的犹豫"。

## 四、常驻配角：Companion化学反应配方

| 角色 | 定位 | 人气来源（原文手法） |
|---|---|---|
| **刘承峰** | 主搭子：半吊子神棍+厨子+嘴炮，"外糙内细" | ①自砸招牌："我其实不会算命，只是个神棍。"宁秋水："麻了。这家伙真是……典中典。"②算命行规做成设定："三不算、两不说"；③喜剧垫恐怖："赛博佛祖""电子木鱼""拉屎的时候怀里抱着圣经会有一种普渡众生的感觉"；④关键时刻真上："大不了一起死，也算有个伴！"⑤反差被点破："大胡子，你这是心有猛虎，细嗅蔷薇啊……" |
| **海哥** | 高阶NPC，"身在泥潭，心向光明"的观察者 | 真身是相机："我一直都很擅长观察并记录一切"；房间灯不亮："这里的灯，不为我照明。""因为我不属于这里。"——压迫场景里给一层悲剧底色，配角即世界观的窗口 |
| **良言** | 团队天花板/嘴刀担当 | 冷面毒舌："那……谁会第一个死？""可能是你。""为什么？""因为你话太多了。"；救人救到底："你不想活，可以下车去死。"（抬头的人） |
| **白潇潇** | 常驻战力+感情线（见第七节） | 递鬼器主动拉仇恨："我体力很好，而且还有其他的鬼器傍身"；冷准则一针见血："不要高估人性。" |
| **诡舍群像** | 田勋（天真/鬼片/溜溜梅）、孟军（冷面/看肥皂剧）、赵二（谜语人："数字啊！"） | 用"回家日常戏"给恐怖降压："咱们诡舍本来就没多少人，你们这一走，这里就更空了。" |

**化学反应公式**：一个装傻（刘承峰）× 一个不接梗（宁秋水翻白眼/无语，"你为什么要把圣经放在厕所？"）+ 危机里的托付升级（从"我跟你混"到"我陪你验证"到替他挡夜），双人关系每单元推进一格。

## 五、反派与诡：造"势"而非造"强"

| 类型 | 模板 | 原文证据 |
|---|---|---|
| **操盘者型反派（红衣男人）** | ①登场即定调"我就是规则"；②欣赏主角而非降智；③主动招揽 | "大势所趋……这个词好！""我，就是这幢大楼里的大势！我可以轻松地造出一个神，也可以转瞬之间就灭掉它！"；他对主角的评价是"你们的故事是最直接，最具有力量感的"，并抛出橄榄枝"要不要加入我？"（逃出生天） |
| **有故事的单体诡** | 前史+执念+可对话，杀与不杀全看规则 | 广修一家（祈雨村，最终"我等那场雨，等了好长时间啊……"）；王文心（逃出生天）；"作恶者"神婆 |
| **无差别灾厄诡** | 无对话、不可谈判，靠环境与音效写 | 长春高校笑男：五张脸在窗外+第六只在床板上，"一边机械地拍着手，一边唱起了那渗人的生日快乐歌" |
| **规则化强度曲线** | 诡的能力被"封印分条解锁"，给出明确的可推演威胁 | 抬头鬼：【手，脚，眼，口】逐条注明效果与冷却（抬头的人）；杀人魔昼/夜的『刀』与时限："『刀』其实是杀人魔杀人需要触发的条件"（雨墓）；黑衣夫人提示"不要淋雨""不要长时间和它对视" |
| **诡的智商** | 诡也会风险评估与配合，才可怕 | 水人"能够在门即将关上还保持镇定，足以说明这只厉鬼的智慧并不低"；公路单元"门口的鬼吸引他们的注意力，窗外的鬼趁机搞事" |
| **人性反派死于自己的规则** | 让施害者被自己造的机器反噬 | 严经理训鬼反被分尸："是你说过的啊……顾客就是上帝！"（亡羊补牢）；蒋义"你图什么？"无人回应（守灵）；导演郑超被主角拧脖子："这种看着自己一点点死去，却没有办法阻止的感觉……是不是很美妙？" |

## 六、对话艺术

1. **信息效率**：宁秋水的提问永远是"三个问题打包"（"这里是哪里？""为什么来？""大巴是什么情况？"），而NPC用沉默/极短答制造压迫——西装男全章只肯说："会死。""而且是……非常凄惨地死去。"（第1章）。
2. **恐怖对话四种措辞模式**：①重复三遍（管家提示、梁月"来陪我吧！"三连、云薇"对不起，可是我不能……"）；②音量最小处藏关键（老人"肉……没……"第三字"熟"被误听成"味"，一个字差出一条人命线）；③礼貌语法+恐怖内容（番外白裙女人："我……忘记……带……钥匙了……""我们……是不是……昨天见过……"）；④断续省略号说话，让读者脑补。
3. **规则/红字说话**：格式统一为【任务】+【线索/提示】；提示全用禁令句与模糊指代——"沾血的信不能送到［女人］的手里""一个［男人］最多只能收到三封信""投票正确指认凶手之后，任务结束（只有一次指认机会）"；私人信件走诗体（"风不点灯，雨不燃烛"）或极简五字（"小心鸢尾花"）。
4. **语言区分度**：宁秋水=短句+反问；刘承峰=川渝口语+自创歪理（"看哈呢？人走远了都……"）；白潇潇=慵懒+眨眼+狠话；良言=绵里藏针；杨眉=叠词撒娇（"嘻嘻""霉运这种东西居然也会传染"）；沈强=中英混插（"这mua的细心""会sunmine的"）做喜剧位。
5. **川渝元素与网感**：方言动词入话（"打整""晓得个屁""夺少？"）；网感做减压阀——"典中典""麻了""苟，才是王道！我杨一博文，要做最苟的苟王！"。恐怖段落零网感，喜剧段落才放。

## 七、情感线：单女主、低占比、道具传情

作者自述："感情线不得不写，我落笔谨慎，篇幅极少，顶着巨大的压力。"文本验证：白潇潇出场即分走"神秘感"位置（诡舍老人/罗生门疑云），推进全靠功能性接触——①道具：溜溜梅（"偷偷吃两个，他不知道"）、梅树手链（"我愿化身石桥"）、递梳子救命、不动声色把拼图揣进他兜里（"回去后再拿出来"）；②战损信任：古宅中她主动拉仇恨"快跑，白姐！"；③台词极简：门口等待只有三个字——"活着回来。"；④越界即刹车："她没喝醉，我也没喝醉。""只是心事太重。"恐怖主线里感情戏只占过场与战后余波，从不进副本解谜核心；她的过往（邙）用番外补完，糖里藏刀。
