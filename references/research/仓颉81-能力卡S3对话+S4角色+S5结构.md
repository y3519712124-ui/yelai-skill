# 仓颉81能力卡·S3对话+ S4角色+ S5结构

> 紧凑格式：触发→步骤→边界→例证

## S3 对话设计

### S3-1 一句一信息法
**触发**：角色需要通过对话传递规则/信息/线索
1. 每句台词只携带一个信息点。不打包。
2. 规则解释拆成短句连发，中间夹听者身体反应（腿软/攥衣角/发抖）
3. 关键信息用最短句（"会死。"两个字）
⚠ 仅限关键信息传递。闲聊可以打包。
📌 "完成任务后，大巴车会来接你们。"——一句一事实。

### S3-2 沉默换挡器
**触发**：对话需要停顿/情绪转折
1. 写沉默（"他没说话"/"沉默了片刻"）
2. 沉默被三种方式打破：①更重的一句话（66%）②环境静写（26%）③尖叫/事件（8%）
3. 沉默后的第一句：比沉默前短一半、重一倍、含扩大化判断
4. 禁用"他叹了口气"糊弄
⚠ 不要连续两次沉默。
📌 西装男沉默后："会死。""而且是……非常凄惨地死去。"——从沉默到重锤。

### S3-3 口语碎块问句法
**触发**：角色需要提问
1. 删掉"什么/为什么/哪里/怎么"等工整疑问词
2. 用口语碎块（"还中场休息？你以为做慈善呢？"）
3. 反问用来表态，不用来求答
4. 主角自问推进推理（"害怕什么呢？"）
⚠ 不要写"他问道：'为什么会这样呢？'"——没人这么说话。
📌 "还中场休息，你以为血门是做慈善的呀？"——零疑问词。

### S3-4 无回答台词术
**触发**：需要表达"回避/恐惧/心虚/默认"
1. 问题抛出
2. 不给回答。插一段沉默描写或环境描写
3. 沉默本身=回答（最有信息量的回答）
4. 切场或换话题
⚠ 不要连用。一段对话最多一次"无回答"。
📌 "选房间了吗？"→ 全场沉默→ 丫末反问"咱们真要一人睡一间？"——沉默=回答。

### S3-5 对话插镜法
**触发**：连续对话需要节奏控制
1. 说1-2句台词→必须插一个非台词段
2. 插入物随烈度升级：闲聊→小动作（翻白眼/喝水）；危机→体感（腿软/攥拳）；高压→声音事件
3. 70%的对话是单句即被截断
⚠ 不适用于快速争吵（连珠炮对话可以3-4句不插）。
📌 宁秋水说一句→刘承峰"腿一软"→再说一句→插环境→再说。

### S3-6 零语气词主角法
**触发**：写主角的台词
1. 主角台词禁用"啊呢吧嘛哦哈"等语气词
2. 语气词留给配角（怂者用"吧"、敷衍者用"嘛"）
3. 主角的"稳"=连语气词都省了
⚠ 主角偶尔在极紧张时可以用一次"吧"。全书不超过5次。
📌 宁秋水全书语气词最少（"吧"27次/"啊"9次——大部分是引用别人的话）。

### S3-7 三遍重复升级法
**触发**：需要用重复制造恐怖/紧张
1. 拟声重复：顿号连排（哒、哒、哒）→机械感
2. 台词重复：省略号连排，逐遍升格标点（……→！→！！）
3. 三遍是极限。第四遍=笑场
⚠ 仅限"最恐惧的3秒"。
📌 "来陪我吧！来陪我！来陪我！！"——三遍，情绪逐遍升格。

### S3-8 沉默后重锤法
**触发**：沉默之后需要说一句话
1. 新句比沉默前的句子短一半
2. 信息量重一倍
3. 含一个"扩大化"判断（从个体扩大到全局）
4. 常配"缓缓道/半晌才道"
⚠ 不要在沉默后说废话。
📌 宁秋水沉默半晌→"尸水……或者说尸油。"——五个字，重锤。

### S3-9 怂闹稳三人序
**触发**：三人以上的对话场景
1. 信息最弱者/最怂者先提问
2. 话痨/权威居中碰撞
3. 主角最后说话——且台词指向下一步行动
⚠ 主角不是不说话。是最后说，说的每一句都是"决定"。
📌 严幼平弱弱举手提问→刘承峰插科打诨→宁秋水一句定论分工。

## S4 角色管理

### S4-1 职业感官挂件法
**触发**：设计主角的"能力"
1. 给主角一个真实职业（兽医/法医/修表匠/护士）
2. 职业的"专业训练"翻译成"超常感官"（兽医→闻得出人血；修表匠→听得出秒针停顿）
3. 第一次出场就自报职业
4. 能力有天花板——只能观察推断，不能打
⚠ 不要给超能力。不要给面板。
📌 "我是医生。""法医？""差不多，兽医。"——一句话，职业+反差+幽默全有了。

### S4-2 怕但比别人小法
**触发**：写主角面对恐怖的反应
1. 主角会怕——心跳快、手心出汗、腿软
2. 但反应比别人"小一格"——别人腿软他只是腿酸，别人叫出声他只是屏住呼吸
3. 用旁观者视角确认（"连他都没多大反应"）
⚠ 不是"不怕"。是不怕到那种程度。
📌 "无论是在发现胖子的人皮，还是在闻到那股血腥味，他的反应都远没有众人那么大。"

### S4-3 炮灰领盒饭术
**触发**：需要"展示规则后果"
1. 炮灰出场2-5章即死
2. 炮灰死前必须"不信邪"（"万一是道具呢？"）
3. 死法=违反规则的结果
4. 死状给一个反常细节（微笑/没有影子/死后不见了）
⚠ 炮灰不是工具人——给他一句让人记住的话。
📌 "万一那只是个道具呢？"→"血也是道具？"——说完这话的人，后来死了。

### S4-4 背叛者种因术
**触发**：需要"人性恶"的恐怖
1. 背叛者在早期必须"示好"（帮过忙/给过信息/救过人）
2. 背叛的动机=恐惧驱动的自保（不是邪恶，是怕死）
3. 背叛的时机=最关键的时刻（在你最需要他的时候）
4. 背叛者的结局=死于自己埋的局
⚠ 背叛者不是反派——是"和你一样怕死的人"。
📌 杜付元早期帮过闻岸→后期诱王九钏夜行→"血门里危险的往往不仅是鬼怪，还有一同进入的伙伴。"

### S4-5 牺牲者遗物法
**触发**：需要一个"让读者哭"的死
1. 牺牲者有一个未完成的心愿
2. 牺牲者有一件遗物（信/照片/物件）
3. 死法=断后（为团队牺牲）
4. 死后遗物引出下一单元
⚠ 让读者哭的不是死亡——是遗物和未完成。
📌 君迢迢："帮我个忙……如果最后我死了，请将这个带到昆华医院……交给一个叫君鹭远的人。"

### S4-6 引导者七分话术
**触发**：需要NPC传递信息但不全给
1. 引导者说话只说七分（留三分不说）
2. 关键信息藏在"重复的动作"里（重复三遍的话=重要提示）
3. 引导者可能是半人半诡
4. 真相揭开时，引导者消散或皈依
⚠ 引导者不是"百科全书"。是"知道但不能全说的人"。
📌 管家尼尔："夫人不喜欢外人进入三楼。"说了三遍——重复=重要提示。

### S4-7 隐藏诡早埋闲笔法
**触发**：需要在团队中安插一个"隐藏的鬼"
1. 选队伍里"最不起眼"的人
2. 早埋一处闲笔（没影子/没吃饭/没换衣服/手很冷）
3. 闲笔一笔带过，不强调
4. 揭露时台词点题（"你不是一直在找自己的头吗？"）
⚠ 闲笔埋在开头。揭露放在60%处。
📌 "鞋柜无男鞋"→"这个家里根本没有男人的鞋子！"→三楼才是鬼。

### S4-8 反派"势"感法
**触发**：需要设计一个有压迫感的反派
1. 反派不降智——他知道你在做什么，他就是不在乎
2. 反派用台词定调："我就是这幢大楼里的大势"
3. 反派欣赏主角（"你不错"比"我要杀你"更可怕）
4. 本单元不退场，留为主线钩
⚠ 反派不是"坏"。是"强到不在乎"。
📌 红衣男人："我可以轻松地造出一个神，也可以转瞬之间就灭掉它！"

### S4-9 感情线道具传情法
**触发**：需要在恐怖故事中安放感情线
1. 感情线占比≤5%
2. 不写"我爱你"——用道具传情（递梳子/留溜溜梅/塞照片）
3. 台词极简（"活着回来。"三个字）
4. 越界即刹车（"她没喝醉，我也没喝醉。""只是心事太重。"）
⚠ 感情线的存在是证明主角是"人"，不是谈恋爱。
📌 白潇潇把拼图偷偷揣进他兜里——"回去后再拿出来"。

## S5 结构控制

### S5-1 单元九拍模板
**触发**：设计一个完整的恐怖副本/单元
1. 进门（大巴/迷雾接引，人数盘点）
2. 落地（NPC接待，埋3个反常细节）
3. 任务（血字：【任务一句+提示≤10字】）
4. 首死（不信邪者2-4章内死，死状给反常细节）
5. 调查（白天线索3件+误判一次方向）
6. 隐藏规则（60%处揭晓"明规则之下还有一层"）
7. 升级（夜袭/鬼当面/减员加速）
8. 生路（解冤/仪式/反杀；允许一次"按提示仍死"）
9. 回归（战利品：鬼器+主线糖+新委托）
⚠ 九拍顺序不可乱。可压缩但不可跳跃。
📌 血门1"照顾老人"14章=全型微缩。

### S5-2 主线糖投放术
**触发**：需要维持跨单元的追读动力
1. 每1-2个单元掉一颗主线糖（拼图碎片/信件/计划名）
2. 优先落在回归章或回归前1章
3. 只给"关系揭示"不给"谜底"
4. 最长旱期250章——靠信件/小情报维持
⚠ 糖不是奖励。是钩子。
📌 第14章"拼上一半"→第59章→第343章→第507章——间隔逐渐拉大。

### S5-3 过渡章三部曲
**触发**：两个单元之间需要衔接
1. 上一门结算（约1章：分战利品+盘点人数+治疗）
2. 主线推进（1-3章：日常戏+世界观补课+关系发展）
3. 新血门前奏（1章收在血字上——预告下一门）
⚠ 过渡章恐怖密度调低但不归零（维持7-8/千字）。
📌 第14-16章：回归→世界观补课→祈雨村血字。

### S5-4 黄金三章法
**触发**：全书开篇
1. 第1章：异常实锤+进入机构+任务发布（三个动作）
2. 第2章：落地+NPC+反常细节（埋钩）
3. 第3章：首死或尖叫（第一次真正的恐怖）
⚠ 世界观说明书压到第一个副本通关后（第14章+）。
📌 第1章"大巴"→第2章"无人的别墅区"→第3章"尖叫"。

### S5-5 单元长度递增法
**触发**：规划多个单元的长度
1. 前期≤24章（读者还在学规矩）
2. 中期32-51章（加支线+深世界观）
3. 后期43-78章（巨兽单元，内部自成"中宇宙"）
⚠ 递增不是线性——有些单元可以突然变短做节奏变化。
📌 祈雨村43章→逃出生天78章→亡羊补牢35章（回缩）。

### S5-6 多线并行切换法
**触发**：同时推进2-3条故事线
1. 2条线：每5-8章切换
2. 3条线：每3-5章切换
3. 每次切换时，留的钩必须比上一次强
4. 每条线每次出场必须比上次多给一点新信息
⚠ 不要让读者"跳过"某条线——如果他们想跳，那条线写得不够好。
📌 主线（拼图）→单元A（副本）→支线（角色过往）→主线→单元B……

### S5-7 伏笔四档距离法
**触发**：埋设伏笔时决定"什么时候回收"
1. 短线（同单元1-20章）：占35%——单元内解谜用
2. 中线（跨单元21-100章）：占30%——连接2-3个单元
3. 长线（100-500章）：占25%——主线推进
4. 全书级（500章+）：占10%——终极伏笔
⚠ 长线伏笔是读者"回头再看发现伏笔"的惊喜来源。
📌 神秘信件第3章埋→第9章露半句→第79章第三封→第215章第四封。

### S5-8 三层嵌套揭示法
**触发**：设计"表层谜题/中层恩怨/深层真相"
1. 表层谜题：每单元解决。解决时中层露一角
2. 中层恩怨：每2-3单元推进。推进时深层露一角
3. 深层真相：全书才完全揭晓
⚠ 每次解表层，必须附带中层或深层的"一角新信息"。不附带=白解。
📌 祈雨村（表层：解冤）→拼图碎片（中层：收集）→盘古计划（深层：真相）。

### S5-9 零恐怖呼吸阀
**触发**：读者连续读了20-30章恐怖内容
1. 安排一章"零恐怖词"的章节
2. 这一章写：纯信息博弈/角色关系/主线推进
3. 恐惧由"信息差"制造，不靠恐怖词
4. 全1002章仅2章零恐怖——物以稀为贵
⚠ 不超过1章。超过就变成日常文了。
📌 第453章"摊牌"——宁秋水与刘博士的权限对峙，零恐怖词，纯智斗。
