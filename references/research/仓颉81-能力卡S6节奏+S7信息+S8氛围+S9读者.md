## S6 节奏调控

### S6-1 恐怖密度恒定法
**触发**：写日常章/过渡章时的恐怖词管理
1. 日常章8-12个恐怖词/千字（血/死/鬼打底）
2. 前中后三段近均匀分布（不集中轰炸）
3. 引爆点全章不超过两处
4. 高潮章才拉到25+/千字
⚠ "血/死"负责氛围，"尖叫/冷汗"负责引爆。分工不同。
📌 前50章恐怖词统计：血286、死283、鬼185——均匀铺撒非集中轰炸。

### S6-2 每2000字喘息法
**触发**：读者连续读了恐怖内容需要喘息
1. 每2000字安排1个喘息区（3-5段）
2. 喘息区配方：1句贫嘴+1个日常动作+1段环境描写
3. 喘息区不要有恐怖词
⚠ 每章平均1.8个喘息点。不多不少。
📌 第3章：恐怖的尖叫后→厨房做饭段（刘承峰骂骂咧咧+聂昭安排分工）=喘息区。

### S6-3 幽默精确制导法
**触发**：需要在恐怖后安插幽默
1. 幽默距恐怖实锤50-150字（最常见区间，占比40%）
2. 幽默让配角承担（刘承峰系统）
3. 引爆段前300字禁幽默
4. 幽默来源：粗口修辞+性格反差+网感吐槽
⚠ 每章约1处。常隔章出现。"卧槽"级粗口前80章仅23次（0.13/千字）。
📌 恐怖实锤→"这么快就忘记了那个胖子了？电视做节目，会把人杀了剥皮？"→50字后刘承峰吐槽。

### S6-4 恐惧递进三层法
**触发**：需要控制读者的恐惧从"不怕"到"很怕"
1. 第一层（1-3章）：禁用"怕/恐/惧"三字。只写异常现象。
2. 第二层（4-6章）：角色开始说"我怕"。
3. 第三层（7章+）：全面恐惧。"怕"字20+次/章。
⚠ 恐惧不是"写怕"写出来的。是"该怕的东西逐渐逼近"写出来的。
📌 第1-3章"怕"字<5次/章→第4-6章8-15次→第7-10章20+次。

### S6-5 长短句情绪切换法
**触发**：需要从一种情绪切换到另一种
1. 长句→短句=从舒缓变紧张（60%）
2. 短句→长句=从紧张变舒缓（25%）
3. 空行切换=情绪转折（10%）
4. 无信号直接切=最暴力最有效（5%，慎用）
📌 "外面的天已经彻底黑了。苍白的灯光照亮了大厅。但不知为何，众人总觉得自己仍旧身处黑暗之中。"——长→短→长。

### S6-6 章尾钩六型轮换法
**触发**：每章结尾需要挂钩子
1. 危机悬置40%（听到/看到即断章）
2. 谜题抛出20%（"这是……尸水"）
3. 反转10%（"血云书院……已经放学了"）
4. 规则/信息揭晓8%（【风不点灯，雨不燃烛】）
5. 主线炸弹10%（"她是盘古计划的起点"）
6. 平中带钩8%（日常收口+低烈度不安）
⚠ 恐怖场面绝不原地解决——听到/看到即断章。
📌 第3章尾"啊！！！"→第4章首"这突如其来的惨叫，打破了别墅的死寂。"

### S6-7 日循环节拍器
**触发**：单元内需要"时间的紧迫感"
1. 白天=调查/人际/线索收集
2. 夜晚=猎杀/恐怖/危机
3. 任务用"活过N日"计时（五日/七日/头七）
4. 日循环=天然的节奏器
⚠ 每个日循环至少推进一个信息点。
📌 黑衣夫人"第一夜"、灯影寺"第四夜"、守灵"第二夜"——日循环标题。

### S6-8 段落长短交替法
**触发**：控制段落的视觉节奏
1. 短段→短段（连续碎段=紧张加速）
2. 长段→短段（长段铺垫→短段重音）
3. 短段→长段（短段悬念→长段展开）
4. 极短段（≤10字）=重音锤
📌 B1数据：S→S 15357次最高——连续短段是主流节奏。

### S6-9 单元密度爬坡法
**触发**：规划一个单元内的恐怖密度变化
1. 前1/4章节：恐怖密度8-9/千字（慢启动）
2. 中1/2：递增到10-12/千字（爬坡）
3. 末1/4：拉到最高（爆点）
4. 单元首章全用陈述句轻起步，末章才允许惊叹重锤
📌 前5章平均8.7→末5章11.6，递增33%。

## S7 信息管理

### S7-1 信息配给制
**触发**：需要控制读者知道多少世界观
1. 每次只给一点。每次给的都是"回答旧问题但打开新问题"
2. 不一次性交代世界观
3. 每条信息都是"上一条的续集+下一条的预告"
⚠ 如果第一章就交代清楚，读者就"知道了"——知道了就没有好奇了。
📌 第1章只给"大巴+黑色别墅+血门"。第14章才补"诅咒+拼图+迷雾终点"。

### S7-2 角色读者信息差法
**触发**：需要制造"替角色着急"的悬念
1. 角色A知道→角色B不知道→读者知道→读者替B着急
2. 角色A不知道→角色B不知道→读者不知道→读者和角色一起怕
3. 每个单元至少1次类型①（抽屉悬念）+1次类型③（共同恐惧）
📌 宁秋水的神秘信件第3章亮出不给内容→第9章放出半句救命——读者知道他有秘密但不知道是什么。

### S7-3 前三章禁"怕"字法
**触发**：写前三章（或任何恐怖单元的前三段）
1. 前三章禁用"怕/恐/惧"三字
2. 只写"异常"（不该在的东西在了/该在的不在了/做了一件不该做的事）
3. 第4章起才允许角色说"我怕"
4. 恐惧是读者自己"长"出来的，不是作者"写"出来的
📌 第1-3章"怕"字<5次/章→第4-6章8-15次→第7章+20+次。

### S7-4 规则文案残缺法
**触发**：写规则怪谈的"规则文案"
1. 规则文案≤3条（任务1句+线索≤3条）
2. 留一处残缺（被划掉的小字/潦草字迹/空白）
3. 残缺=有人不想让你知道/写字的人快死了
4. 方括号泛指制造解读谜题（［女人］［男人］）
📌 鹅村木牌【禁止斗殴/禁止欺凌/禁止偷盗/……也……哦】——第四行被划掉到"只能依稀辨认两字"。

### S7-5 层层揭示附带法
**触发**：单元解密时需要推进主线
1. 每次解表层谜题→必须附带中层或深层的"一角新信息"
2. 不附带=白解（读者觉得这单元和主线无关）
3. 附带的方式：发现一个物件/听到一个名字/看到一处异常
📌 祈雨村解冤（表层）→发现拼图碎片（中层）→碎片引出"诡舍筛选目的"（深层一角）。

### S7-6 标题最小具体法
**触发**：给章节起标题
1. 2-6字具体名词或动作词（大巴/尖叫/上楼/肉没味）
2. 不剧透、不抒情、不用抽象词
3. 抽象词只留给主线揭秘章（真/谜/规则）
4. 序列标记"（一）（二）"用于连续高潮
📌 大巴/尖叫/肉没味/背包/藏鬼/寻尸——全是"画面"不是"概念"。

### S7-7 勾名录暗改法
**触发**：需要设计"系统层面的阴谋"
1. 让一个"官方文件"被篡改
2. 篡改的痕迹极小（多一个字/少一个字/一个字换了偏旁）
3. 主角通过"对比"发现异常
4. 篡改的"手"贯穿全书（暗线）
📌 "李念"被改为"李念恩"——多一个字。勾魂车按册勾人，勾成了"另一个李念恩"。

### S7-8 首章只给异常法
**触发**：写全书或单元的第一章
1. 第1章只给"异常"——不给解释、不给世界观、不给背景
2. 异常=违反常识的一件事（没有司机的大巴/自动开门的药房/镜子里多出来的人）
3. 读者带着"为什么"翻到第2章
4. 解释推到第14章+（第一个副本通关后）
📌 第1章大巴：无司机+血人+诡异别墅——三个异常，零解释。

### S7-9 真相分层扣留法
**触发**：全书的大真相需要分层揭晓
1. 真相分三层：表层（每单元）→中层（跨单元）→深层（全书）
2. 每层只揭一角——解A问题时看到B问题的影子
3. 深层真相只在大结局完全揭晓
4. 每次揭晓都让读者"重新理解"前面的情节
📌 拼图（表层收集）→"拼图就是寿衣"（中层真相）→"诡舍筛选的是能对抗'灰'的人"（深层真相）。

## S8 氛围营造

### S8-1 颜色恐怖编码法
**触发**：需要用颜色暗示恐怖类型
1. 红色=危险预告（血/红衣/红灯/红字）
2. 白色=死亡标记（白衣/白布/白灯/苍白）
3. 黑色=未知（黑暗/黑影/黑气）
4. 金色=超越自然（金光/金香）
📌 尸体"脸上挂着诡异的微笑"+穿白色病号服——白色=死亡标记。

### S8-2 身体部位恐怖法
**触发**：需要选择恐怖的"身体部位"
1. 眼睛（25%）=看到了不该看的
2. 手（20%）=碰到了不该碰的
3. 嘴（18%）=说出了不该说的
4. 头发（12%）=感觉不对
5. 皮肤（15%）=触感不对
6. 骨头（10%）=听到了不该听的
📌 "一只苍白的手"——手=碰到不该碰的。碰了三号货架的药。

### S8-3 水的形态情绪法
**触发**：需要用水传递情绪
1. 雨=压抑/悲伤/笼罩（"下雨了=事情不好了"）
2. 自来水=日常中的异常（"水龙头自己开了"）
3. 血=代价（"血滴在地上"）
4. 泪=释放（"他终于哭了"）
📌 "天花板渗黄褐色的液体"→"滴答——嘀嗒——"→是尸水。水=恐怖的载体。

### S8-4 镜像三阶恐怖法
**触发**：需要用镜子/反射面制造恐怖
1. 第一阶：镜子里多了一个人（经典）
2. 第二阶：镜中的"你"做了不一样的动作（高级）
3. 第三阶：镜子里没有你（终极——你不存在了）
📌 理发店的三面镜→无限延伸的镜廊尽头→椅子上坐着一个"人"→但椅子上是空的。

### S8-5 门的功能先决法
**触发**：写任何"门"的场景
1. 先想门的功能：打开=诱惑/入口。关着=禁止/秘密。消失=没有退路
2. 从里面锁住=有东西不想出来
3. 从外面锁住=有东西不想让你出去
4. 写门之前先想"这扇门要做什么"
📌 "通往三楼的铁门锁被打开了……就在自己的身后！"——门+锁=有东西出来了。

### S8-6 时间装置异常法
**触发**：需要"理性世界崩塌"的标记
1. 钟表停了=时间卡住了
2. 钟表倒走=时间在退
3. 钟表快进=跳过了什么
4. 倒计时=死亡倒数可视化
📌 挂钟"秒针每走到那个位置就顿一下"→"没有4"→四点钟被掰掉了。

### S8-7 气味定性法
**触发**：需要用气味传递信息
1. 气味要具体（不是"怪味"，是"血腥味混着木头腐朽味"）
2. 用职业认知定性（兽医→"人血是铁锈味"）
3. 气味既是氛围又是线索
📌 "人血是有一股明显的铁锈味……我可以非常明确地告诉各位，当时那个红绿灯上的血百分之百是人血。"

### S8-8 触觉恐惧法
**触发**：需要用触觉制造恐怖
1. 触觉恐怖=皮肤接触到"不该存在的触感"
2. 最恐怖的触觉：冷（不是冰的冷，是"尸体般的冷"）/黏（不知道是什么的液体）/软（应该是硬的东西是软的）
3. 触觉确认=恐惧从"看到"升级为"碰到"
📌 "一股刺骨的寒冷，从他的手腕迅速蔓延到了全身。"（第133章）——碰到了不该碰的东西。

### S8-9 寂静配反常理由法
**触发**：需要写"安静"的恐怖
1. 安静必须配一个"反常理由"（该有声处无声=有鬼）
2. 安静写成"双段锤"："周围很寂静。"/"寂静得可怕。"（两个独立段）
3. 要"更可怕"不是加声音——是让声音停下
📌 "周围很寂静。寂静得可怕。"（第1章）——深夜的别墅区，该有虫叫鸟叫的，什么声音都没有。

## S9 读者操控

### S9-1 后劲三件套
**触发**：需要读者"看完之后睡不着"
1. 恐怖物来自"读者每天都碰的东西"
2. 恐怖没有"解决"（读者不知道那东西还在不在）
3. 最后一个画面是"静止的日常"（"他就坐在那儿，一动不动"）
📌 "洗澡还害怕淋浴喷头给我吸进去"——日常物+未解决=后劲。

### S9-2 名场面四件套
**触发**：需要制造一个被读者反复提到的"名场面"
1. 日常场景（食堂/红绿灯/教学楼）
2. 违反常识的细节（食堂的菜是人/红绿灯上挂着人皮）
3. 被迫目睹的视角（主角不得不看）
4. 过于具体的细节（读者脑中挥之不去）
📌 "长春高校食堂"——日常场景+菜是人+主角必须吃+"肉没味"三个字。

### S9-3 共鸣人间真实法
**触发**：需要读者说"这段写的就是我"
1. 恐怖底下藏一个"社会真实"（久病床前/底层选择/家庭牺牲）
2. 不说教——让读者自己从恐怖中"读出"社会隐喻
3. 角色的选择=读者可能面临的选择
📌 祈雨村=饥荒年代"易子而食"。血云书院=教育内卷"逼死孩子"。逃出生天=大楼=阶层。

### S9-4 猜不到反转法
**触发**：需要设计一个读者猜不到的反转
1. 线索在前文都有，但被读者"合理化"了
2. 反转不是"谁做的"，是"为什么做"（动机反转比身份反转更难猜）
3. 反转发生在读者"以为已经安全了"的时候
📌 "三楼才是鬼"——读者以为鬼在二楼（老人），实际鬼在三楼。线索（无男鞋）都有，但被读者忽略了。

### S9-5 猜到但没想到法
**触发**：需要"读者猜到方向但没想到细节"
1. 读者猜到"这个人是鬼"——但没想到"它为什么这样做"的理由
2. 方向让读者猜到（成就感），细节让读者震惊（惊喜感）
📌 读者猜到老人有问题→但没想到"老人是饿死的女孩的母亲"→动机一揭，恐变悲。

### S9-6 情感投资养成法
**触发**：需要读者在乎一个角色（然后伤害他们）
1. 角色出场时给一个"人味"细节（不是技能，是习惯/口头禅/小动作）
2. 中期给角色一个"选择"（在恐怖面前的人性选择）
3. 死亡前给一个"未完成"
📌 刘承峰的"卧槽"和义气→帮聂昭挡刀→"老周头你答应我的"——三步投资。

### S9-7 讨论点开放法
**触发**：需要读者自发讨论/争论
1. 设计有"解读空间"的段落（不止一种理解）
2. 设计"道德困境"（你怎么办？）
3. 设计"推翻前文认知"的反转
📌 "诡舍筛选的是能对抗'灰'的人"——那被筛选掉的人呢？他们的死是"应该的"吗？读者吵翻了。

### S9-8 最痛死法三要素
**触发**：需要一个让读者最难受的角色死亡
1. 那个角色"还有一个心愿没完成"
2. 那个角色"刚刚变好了"
3. 那个角色的死"毫无意义"（不是英雄式的，就是运气不好）
📌 君迢迢：心愿未完成（照片没送到）+刚展现了善良（帮聂昭）+死得毫无意义（被活剥皮）。

### S9-9 后遗症传播法
**触发**：需要读者看完后"行为改变"（不敢关灯/不敢照镜子）
1. 恐怖物是"读者每天必须接触"的
2. 恐怖发生在"读者认为安全"的时间和地点（白天/家里/人多的地方）
3. 恐怖没有任何"合理解释"（不是梦/不是幻觉/不是心理作用）
📌 "洗澡还害怕淋浴喷头给我吸进去""酒店不敢去，寺庙不敢留，厕所门开着"——日常物+安全时空+无法解释=后遗症。
